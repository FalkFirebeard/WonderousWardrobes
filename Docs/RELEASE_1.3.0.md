# Wonderous Wardrobes 1.3.0 — HyThief Compatibility

- Adds optional compatibility with HyThief's existing container theft, visual witness and native NPC response systems.
- Conservatively marks eligible newly generated wardrobes as faction-owned or nearby-owned. There are 215 eligible placement opportunities; existing loot weights and empty chances are unchanged.
- Keeps all 16 wardrobe variants, 54 slots, recipes, visuals, native opening and inventory persistence unchanged.
- Both mods remain standalone. No bridge plugin or required dependency is added.
- Player-placed wardrobes stay unowned. Existing generated wardrobes without metadata are not retroactively migrated.
- Ownership does not make every NPC a witness; HyThief's existing supported-role and perception rules still apply.
- Targets Hytale **=0.7.2**.
